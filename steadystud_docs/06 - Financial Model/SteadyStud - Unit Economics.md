# SteadyStud — Unit economics (DIY-first, DTC + retail)

## Pricing anchors (directional)
Commodity magnetic stud finders commonly appear in the low-teens price band. Premium must justify itself with workflow + outcomes.

## Pricing strategy (chosen)
- **DTC MSRP:** $16.99–$19.99 (default modeling at $18.99)
- **Retail MSRP:** likely similar, but unit economics must support **wholesale pricing** (~50% of MSRP, varies by retailer/distributor).

## DTC unit economics components
- COGS (body + magnets + assembly)
- finishing (anodize + laser mark)
- packaging + insert (retail-quality)
- payment processing
- shipping cost vs shipping fee charged
- returns
- CAC / creator seeding costs

## Retail unit economics components
- wholesale price
- retailer margin + distributor margin (if used)
- chargebacks, slotting (sometimes), returns
- packaging/UPC/compliance

## Key output metrics
- Contribution margin per DTC order
- Break-even CAC
- Wholesale gross margin per unit
- Return-rate sensitivity

Truth constraint: magnetic stud finders detect **fasteners**.
