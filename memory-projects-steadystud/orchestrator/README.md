# SteadyStud lane — Orchestrator workflow

## What this lane cares about
Fast, correct iteration on manufacturability + quoting + go-to-market constraints.

## Definition of Done (per packet)
- The output moves one concrete bottleneck forward (quote packet, vendor shortlist, BOM target, finish decision).
- Assumptions and tolerances are explicit.
- Vendor communication drafts are ready (but not sent without approval).
